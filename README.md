# 🤖 CodeSoft Internship – Machine Learning Projects

## 📋 Overview
This repository contains the **Machine Learning projects** completed during my internship at **CodeSoft**.  
Each project focuses on applying fundamental ML concepts — including **data preprocessing**, **feature engineering**, **model training**, and **evaluation** — to solve real-world classification and prediction problems.

## 🧩 Projects Included

### 1️⃣ Titanic Survival Prediction
**Goal:** Predict whether a passenger survived the Titanic disaster using demographic and ticket information.  

**Key Steps:**
- Data cleaning and handling missing values.  
- Feature encoding (Sex, Embarked, etc.).  
- Building predictive models (Logistic Regression, Decision Tree, Random Forest).  
- Evaluating accuracy and ROC-AUC.

**Tech Stack:**  
`Python`, `Pandas`, `NumPy`, `Scikit-learn`, `Matplotlib`, `Seaborn`

**Notebook:**  
[`CODSOFT_TITANIC SURVIVAL PREDICTION.ipynb`](./CODSOFT_TITANIC%20SURVIVAL%20PREDICTION.ipynb)

---

### 2️⃣ Credit Card Fraud Detection
**Goal:** Detect fraudulent credit card transactions using supervised learning models.  

**Key Steps:**
- Worked with a highly imbalanced dataset.  
- Applied **undersampling/oversampling** to balance classes.  
- Built classification models using **Logistic Regression**, **Random Forest**, and **XGBoost**.  
- Evaluated model using **Precision**, **Recall**, and **F1-Score** to minimize false negatives.

**Tech Stack:**  
`Python`, `Pandas`, `NumPy`, `Scikit-learn`, `Matplotlib`, `XGBoost`

**Notebook:**  
[`CodSoft-Credit-Card-Fraud-Detection.ipynb`](./CodSoft-Credit-Card-Fraud-Detection.ipynb)

---

### 3️⃣ Iris Flower Classification
**Goal:** Classify iris flowers into species (Setosa, Versicolor, Virginica) based on sepal and petal measurements.  

**Key Steps:**
- Data visualization and pattern analysis.  
- Model training using **K-Nearest Neighbors (KNN)** and **Support Vector Machines (SVM)**.  
- Performance evaluation using accuracy metrics.  
- Compared multiple algorithms for best prediction results.

**Tech Stack:**  
`Python`, `Pandas`, `Scikit-learn`, `Matplotlib`, `Seaborn`

**Notebook:**  
[`CodSoft-iris-flower-classification.ipynb`](./CodSoft-iris-flower-classification.ipynb)
